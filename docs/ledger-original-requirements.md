# 账单系统

## 功能

### 账单

#### 账单列表

字段：
- 时间
    - 必填
- 消费金额
    - 必填
    - 正数：支出
    - 负数：退款或部分退款
- 消费项目
    - 必填
- 标签
    - 选填
    - 输入关键词进行模糊搜索
        - 如果没有可匹配的，新增交易数据时直接新增标签
- 总预算剩余
- 项目预算剩余
- 备注
    - 选填

操作
- 新增
- 修改
- 删除

### 预算

每月总预算：所有项目类型预算合计

项目类型：每个项目类型的预算
- 修改预算

### 统计

默认页面

日统计
- 总消费金额
- 每个消费项目的消费金额
- 默认今日，可选择日期切换到其他日期

本周统计
- 总消费金额
- 每个消费项目的消费金额
- 默认本周，可选择周历切换到其他周

本月统计
- 总消费金额
- 每个消费项目的消费金额
- 默认本月，可选择月历切换到其他月

本年统计
- 总消费金额
- 每个消费项目的消费金额
- 默认本年，可选择年历切换到其他年

预算统计
- 本月预算总额
    - 本月支出
    - 预算剩余：本月预算总额-本月支出
        - 正数为有剩余
        - 负数为超支
        - 0为用完了
- 上月预算总额
    - 上月支出
    - 上月预算剩余：上月预算总额-上月支出
        - 正数为有剩余
        - 负数为超支
        - 0为用完了
- 跟上月同比
    - 上涨显示 ↑
    - 下降显示 ↓
    - 持平显示 -
- 近12个月环比
- 本年环比
- 近12个月
    - 超支月数
    - 有剩余月数
    - 为0月数
- 本年
    - 超支月数
    - 有剩余月数
    - 为0月数
- 预算剩余
    - 本月剩余
    - 本年剩余
        - 本年每月合计
    - 总剩余
        - 所有年合计
    - 数据说明
        - 正数为剩余
        - 负数为超支
        - 0 为无


### 管理

#### 谷歌验证码

绑定
- 首次登录需绑定谷歌验证码
- 绑定后设置密码
- 本地无缓存强制验证谷歌验证码才可登录进入
- 修改密码时需要验证谷歌验证码
- 密码错误3次验证谷歌验证码
    - 通过后选择继续输入密码和修改密码

解绑
- 输入谷歌验证码并二次确认，解绑成功的同时清空账单系统的所有数据

#### 消费项目管理

字段：
- 项目名称
- 子项目名称

操作：
- 新增
    - 如果要新增一级项目，上级项目选择无
    - 子项目和创建无限级别，每个级别都可设置预算
- 修改
    - 只能修改名称和预算
    - 不能修改级别
- 删除
    - 未产生交易数据可删除
    - 已产生交易数据不可删除

#### 标签管理

字段：
- 标签名称

操作：
- 新增
    - 在
- 修改
- 删除
    - 已绑定交易数据的标签不可删除
    - 未绑定交易数据的标签可删除
