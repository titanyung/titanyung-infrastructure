# Ledger · 独立账单系统

独立于现有 `bill.titanyung.top` 的新账本，目标域名为 `ledger.titanyung.top`。数据库、服务和端口都与旧 Bill 分离。

## 功能与口径

- 账单：时间、正数支出/负数退款、消费项目、标签（逗号分隔，保存时自动创建新标签）、备注，支持新增、修改、删除。
- 账单周期：每月 13 日零时起至次月 12 日 23:59:59 止；例如 `2026-10` 周期为 2026-10-13 至 2026-11-12。13 日出上期账单，上期为上月 13 日至本月 12 日。日、周仍按自然日/自然周，账单年为 1 月 13 日至次年 1 月 12 日。
- 导出：账单页选择起止日期后下载 UTF-8 CSV，包含账单 ID、时间、类型、金额、项目、标签、备注。通常默认最近一个已结算账单周期；在正式起点之后尚无已结算周期时，默认正式起点至今日，不显示上线前的日期。自选范围最多连续 30 天，完整的 31 天账单周期或自然月例外。仅已登录用户可导出。
- 预算：一级项目预算的和为每期总预算；子项目预算独立对比，不重复计入总额。预算调整从调整周期生效，既往周期保持旧额度；上线时尚未设预算的首个不完整周期沿用首次设定的预算，不修改旧预算记录。
- 统计：日、周、账单月、账单年总额和项目拆分；本期/上期预算、支出、剩余；所选周期各级项目的预算、直接支出、含子项支出、剩余及较上期支出；周期环比在“近 12 期”和“本年”间单栏切换，每期展开查看相同口径的各项目明细；本账单年及上线以来剩余累计。
- 管理：无限级消费项目、标签、首次绑定 TOTP 后设置密码。未验证的浏览器首次登录需密码加 TOTP；成功后在该浏览器保存受签名保护的可信凭证，一年内再次登录只需密码，成功登录会续期。清除网站数据、凭证到期、修改或重置密码后需再次验证 TOTP。密码输错 3 次仍需 TOTP 恢复，修改密码仍需 TOTP。解绑 TOTP 需二次确认，**只清空新账本数据库**。

正式统计起点为 `2026-10-13 00:00:00`；此前测试期不进入默认统计，不导入旧 Bill 数据。数据库使用 SQLite WAL，金额以整数分存储。

## 项目内自动入账

`ingest.py` 是仅供已经获得 DMIT SSH 管理权限的自动化调用的命令行接口，**不是公开 HTTP API**，不需要网页密码、Cookie 或 TOTP。`categories` 列出消费项目；`add` 从标准输入接收一笔 JSON 流水并原子写入 SQLite。必须提供稳定且唯一的 `source_id`，同编号同内容重试返回 `already_exists`，同编号不同内容拒绝写入。消费项目必须已存在，可用 `category_id` 或从一级到末级的 `category_path` 定位；脚本不会猜测或自动创建项目。

示例输入（金额为元；正数支出、负数退款；时间为北京时间）：

```json
{"source_id":"bank-20261013-0001","occurred_at":"2026-10-13 12:34","amount":"12.50","category_path":["生活","饮食"],"tags":["午餐"],"note":"消费流水导入"}
```

在有权限的服务器终端运行 `python3 /opt/ledger-system/ingest.py categories`，或把单笔 JSON 送至 `python3 /opt/ledger-system/ingest.py add` 的标准输入。不能把服务器 SSH 私钥、网页密码、验证码、环境文件或真实消费流水纳入源代码交接包。账单被网页手动删除后，原 `source_id` 重试会报错并要求人工核对，不会悄悄补写。

## 本地运行

设置 `LEDGER_SECRET_KEY`（至少 32 字符）、`LEDGER_SETUP_TOKEN`（至少 24 字符）、`LEDGER_DATABASE` 后，安装 `requirements.txt`，运行 `python app.py`。生产环境用 Gunicorn 在 `127.0.0.1:28908` 提供服务，由 Nginx 提供 HTTPS。

首次访问需输入初始化密钥，再扫描 TOTP 二维码、确认六位代码并设置至少 10 位密码。初始化密钥保存在服务端环境文件中，不在网页展示。

## 测试

`python -m unittest discover -s tests -v`

## 备份

每天 03:10 使用 SQLite backup API 在 `/var/lib/ledger-system/backups/` 保存一致性快照，文件仅账本服务账户可读；不自动删除旧快照。部署脚本不接触 `/opt/apps/bill` 或旧 Bill 数据库。解绑前请先把备份复制到另一台机器；网页解绑不可撤销。
